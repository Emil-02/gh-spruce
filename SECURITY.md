# Security Policy

gh-spruce only reads repository metadata and file *names*; it never downloads or
prints the contents of files it flags as secrets. Changes are only made after you
confirm them, and by default through pull requests.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub Security Advisories](https://github.com/Emil-02/gh-spruce/security/advisories/new).
You will get a response within 7 days.
