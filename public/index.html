🌲 gh-spruce ★ Star on GitHub

How healthy is your GitHub profile?

gh-spruce scores every public repository from 0 to 100 (license, README, CI, topics, secrets, and more), tells you what to fix, and gives you a card for your profile README.

Try Emil-02 · sindresorhus · charmbracelet

📋 Audit

15 checks per repository: README, license, description, topics, CI and its status, screenshots, .gitignore, committed build output, large files, leaked .env files and more.

🛠️ Fix

The CLI opens one pull request per repository with a LICENSE, a CI workflow for your stack, a README skeleton, .gitignore and SECURITY.md.

🏅 Share

Add a live health card to your profile and a badge to every repository. No sign-up and no install needed.

Add the card to your profile README

Fix everything from your terminal

gh extension install Emil-02/gh-spruce
gh spruce fix --dry-run

The CLI also audits private repositories and scans the full file tree.
